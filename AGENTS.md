# Agent rules
Read README.md, catalog/file-index.json, bindings/source-map.json and evidence/current-status.md first.
This is a metadata index, not a new canon authority or production selection.
Resolve a source-root label and relative filename through the user's authorized original storage. Retrieve actual bytes before making source claims.
Never infer approval from a filename. Creator approval, source integrity, visual review and release authorization are separate.
Do not move, delete, rename or overwrite bound source files. Do not automatically mirror snapshots back to source folders.
No artwork generation, model installation, synchronization service, external message or publication is authorized by this index.
Keep credentials and unrelated personal/workplace data out of this repository.
