# Suntari Production Hub
Private navigation and evidence index for existing Suntari Comics work.

## Start here
- [Cursor agent handoff](CURSOR_HANDOFF.md): exact source routes, validation task and approval boundaries.
- [File index](catalog/file-index.json): relative filenames, source-root labels, sizes and timestamps; file contents are not copied.
- [Source map](bindings/source-map.json): identifies the three existing folder roles.
- [Current checkpoint](evidence/current-status.md): known installation and validation boundaries.
- [Collection evidence](evidence/index-check.json): scope and source-write count.
- [Agent rules](AGENTS.md): how to use this index safely.

## Existing hierarchy
The orchestrator folder, execution folder and private production library stay where they are. This repository is separate. No source files were moved, renamed, deleted or overwritten. No local repository clone or synchronization service was installed.

## What the assistant can see
The connected GitHub integration can read this private repository. This index locates existing files, but it does not grant access to their contents or guarantee access in every future chat. Use connected workstation/storage tools for original bytes.
Source documents, artwork and the exact ComfyUI revision 2 workflow are not uploaded here. Content snapshots require explicit approval for those sources and this destination.

## Refresh
This is a dated index, not automatic synchronization. Refresh only when requested and record the time and coverage. Missing entries do not prove that a file does not exist elsewhere.
